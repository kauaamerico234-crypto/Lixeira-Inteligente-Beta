# Lixeira Inteligente - Beta

## Descrição
Este projeto tem como objetivo simular o funcionamento de uma lixeira inteligente, utilizando conceitos de programação orientada a objetos em Java. O sistema permite organizar e classificar materiais de forma estruturada, seguindo boas práticas de desenvolvimento.

## Funcionalidades
- Cadastro de materiais  
- Classificação por categorias  
- Organização baseada em arquitetura MVC  

## Tecnologias e Conceitos Aplicados
- Java (linguagem principal)  
- Programação Orientada a Objetos (POO)  
- Arquitetura MVC (Model-View-Controller)  
- Estrutura em camadas (model, service, view)  

## Estrutura do Projeto
- src/ → código fonte do sistema  
- docs/ → documentação do projeto  

## Observações
Este projeto foi desenvolvido para fins acadêmicos
  
## Como rodar
Abra o projeto no VS Code e execute view/Main.java

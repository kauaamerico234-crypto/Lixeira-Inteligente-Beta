# 🗑️ Lixeira Inteligente 
---

## Descrição

Projeto desenvolvido em **Java** com o objetivo de simular uma **lixeira inteligente**, aplicando conceitos de Programação Orientada a Objetos (POO) e arquitetura MVC (Model-View-Controller).

O sistema permite o cadastro e classificação de materiais, simulando um processo de separação automática de resíduos.

---

## Funcionalidades

- Cadastro de materiais  
- Separação entre materiais recicláveis e orgânicos  
- Organização por categorias  
- Classificação automática de materiais  
- Estrutura organizada em MVC
